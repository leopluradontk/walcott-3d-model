Walcott 3D · iPad setup

  1. Open the published GitHub Pages model link in Safari.
  2. Let the overview finish loading. Open ☰ Controls and tap Save for offline.
  3. Keep Safari open and connected until it says Complete model saved for offline use on this device.
  4. Tap Safari’s Share button, then Add to Home Screen and Add.
  5. Open the new Home Screen app while online. Tap Save for offline there too and wait for completion. This ensures the Home Screen app has its own complete offline copy.
  6. Test with Airplane Mode: close and reopen the app, isolate a phase, and select a component to open its hologram.

Controls

Drag to orbit; pinch to zoom; use two fingers to pan. The movement pad and navigation modes are in Controls. Select a component for its hologram. Use the phase buttons for detailed geometry.

Updates and storage

Safari/iPadOS can remove saved website data when storage is low or website data is cleared. Reopen online and save again if offline loading fails. After a model update, reopen online and save the new version again.
